# LarpLand Launcher

Лаунчер сборки LarpLand для Minecraft: ставит игру, NeoForge, Java и модпак, следит за обновлениями и запускает клиент. Приложение WPF на .NET 8 для Windows 10 и 11.

## Состав

| Компонент | Версия |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.251 |
| Java | 21 (ставится лаунчером) |
| Лаунчер | 19.09.26hotfix |
| Среда | .NET 8 (WPF, Windows 10/11) |

## Что делает лаунчер

- Ставит Minecraft и NeoForge молча, без окон установщика, и сам чинит профиль, если он остался недоделанным.
- Качает модпак одним архивом и распаковывает его в папку игры. Папки `mods`, `config` и `resourcepacks` при обновлении перезаписываются целиком, поэтому состав сборки у всех одинаковый.
- Файлы игрока не трогает: `servers.dat`, `options.txt`, `optionsof.txt` и `optionsshaders.txt` из архива ставятся только на пустое место, а свои возвращаются на место после распаковки. Сбросить настройки игры на те, что лежат в сборке, можно кнопкой «Перекачать сборку» - лаунчер спросит об этом отдельно.
- Продолжает оборванную загрузку с места обрыва: недокачанный архив остаётся на диске, следующая попытка дотягивает остаток по HTTP Range.
- Проверяет, что скачалось: архив открывается как zip перед распаковкой, после распаковки считает моды, а повреждённые jar в `libraries`, `versions` и `mods` находит и перекачивает.
- Переживает недружелюбную сеть: при обрыве TLS сужает число потоков загрузки и повторяет установку, а игроку показывает человеческое объяснение вместо стека исключения.
- Обновляет сам себя: новая версия скачивается из релиза и подменяет exe, старый файл возвращается, если подмена не прошла.
- Проверяет систему: сборка Windows, Visual C++ 2015-2022, WebView2, аппаратное ускорение, память, права на папки, свободное место, путь к игре и наличие Java.
- Ловит тихие падения игры: вывод процесса пишется в `game-output.log`, а при вылете лаунчер показывает самые важные строки лога и путь к нему.
- Вход лицензионный через Microsoft или оффлайн по нику (латиница, цифры и `_`, от 3 до 16 символов).
- Показывает статус в Discord, когда владелец сборки завёл своё приложение: идентификатор берётся из `discord_app_id.txt` в репозитории версий, пересобирать лаунчер для этого не нужно.
- Пишет подробный лог в `latest.log` рядом с настройками: версии с сервера, этапы установки, путь к Java, профиль запуска, вход, смену папки и языка.

## Интерфейс

Пиксельный стиль в голубой гамме: неподвижная ночная сцена с горами, луной и водой, по которой переливаются блики, и пиксельный куб, который можно крутить мышью. Кнопка с глазом в шапке убирает интерфейс, оставляя один фон. Тема настраивается двумя цветами - основным и акцентным; в наборе 16 пресетов, свои сохраняются рядом с ними. Фон переключается между анимированной сценой, переливами темы и минимализмом. Интерфейс на русском и английском.

## Версии

Версия лаунчера это дата выпуска: `19.09.26` в интерфейсе и `2026.09.19` в файлах версий. Второй выпуск за день получает суффикс - `hotfix` или `v2`, `v3`. Сравнением версий занимается `Core/ReleaseVersion`.

Обновления берутся из репозитория [stepk1noff/versions](https://github.com/stepk1noff/versions):

| Файл | За что отвечает |
| --- | --- |
| `launcher_version.txt` | Самообновление лаунчера |
| `modpack_version.txt` | Обновление модпака |
| `discord_app_id.txt` | Идентификатор приложения Discord для статуса (можно оставить пустым) |

Модпак лежит в релизе репозитория [stepk1noff/modpack](https://github.com/stepk1noff/modpack) как `release.zip`.

## Сборка

```powershell
dotnet build -c Release
dotnet run
```

Распространяемый файл собирается одной командой после очистки:

```powershell
Remove-Item -Recurse -Force obj, bin, publish
dotnet publish LarpLand.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

На выходе `publish/LarpLand.exe` - самодостаточный файл без установленного .NET.
